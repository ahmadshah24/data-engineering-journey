# Git & GitHub Complete Notes

## What Is Git?
Git is a version control system used to:
- track code changes
- save project history
- collaborate with others
- manage projects professionally

---

# What Is GitHub?
GitHub is a cloud platform where Git repositories are stored online.

Used for:
- portfolio projects
- collaboration
- backups
- open-source projects

---

# Install Git

## Download
https://git-scm.com/download/win

## Verify Installation

```bash
git --version
```

Expected:

```plaintext
git version 2.xx.x.windows.x
```

---

# Configure Git

## Set Username

```bash
git config --global user.name "Ahmad"
```

## Set Email

```bash
git config --global user.email "your-email@gmail.com"
```

## Verify Config

```bash
git config --list
```

---

# Generate SSH Key

## Create SSH Key

```bash
ssh-keygen -t ed25519 -C "your-email@gmail.com"
```

Press Enter for default location.

---

# Start SSH Agent

## PowerShell

```powershell
Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
```

---

# Add SSH Key

```bash
ssh-add ~/.ssh/id_ed25519
```

---

# Show Public Key

```bash
cat ~/.ssh/id_ed25519.pub
```

Copy the FULL output.

Starts with:

```plaintext
ssh-ed25519
```

---

# Add SSH Key To GitHub

## Open
https://github.com/settings/keys

## Steps
- Click "New SSH key"
- Add title
- Paste public key
- Click "Add SSH key"

---

# Test SSH Connection

```bash
ssh -T git@github.com
```

Expected:

```plaintext
Hi username! You've successfully authenticated
```

# Notes

- GitHub does not show empty folders
- Use `.gitkeep` for empty folders
- Never share private SSH keys
- Only share public keys
- Commit changes regularly
- Push projects to GitHub often
